A bit about me

I'm in my final year of BCA, and most of what I know about the web I've learned by actually shipping small projects rather than only reading theory. That started with plain HTML and CSS — layouts, grids, flexbox, getting spacing to behave — and has since grown into picking apart JavaScript and, more recently, the MERN stack.

Alongside that, my coursework has pushed me through data structures, database management and networking, which shapes how I think about a project before I touch a single tag — what the data looks like, how it should be structured, and only then how it should look.
